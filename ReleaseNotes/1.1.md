- **Protects your originals.** If the resized images would be saved over the files you're resizing, PixelShift now warns first, even when "Ask before replacing" is off.
- **Handles huge photos.** Large images are read at the size they're needed instead of in full, so big batches use far less memory, and oversized results fail with a clear message instead of crashing.
- **"Keep all" really keeps all.** Color labels, Lightroom keywords and other XMP-only details now carry over. "Keep all except location" also removes place names stored in XMP.
- **Safer saving.** If saving over a file fails partway, the original is restored.
- **New Settings window (⌘,)** to turn automatic update checks and installs on or off at any time.
